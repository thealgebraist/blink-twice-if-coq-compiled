Divergence 3.1: Block Margin Collapsing

Normative CSS 2.1 §8.3.1 vs. WHATWG Quirks Mode Margin Dropping

In standards mode, container-start vertical margins push the first child down. In Quirks Mode (and in table cells <td>), Blink LayoutNG's MarginStrut drops quirky margins entirely.

W3C CSS 2.1 §8.3.1 (Standards Mode)

<!DOCTYPE html>
24px
<p> Paragraph with 24px margin-top
✓ Normative Behavior: The 24px margin is preserved, creating vertical breathing room between the container's inner border edge and the paragraph.

Chromium Blink Quirks Mode (MarginStrut.cc)

No DOCTYPE (Quirks)
<p> Paragraph touches top border flush (0px gap!)
✗ Divergence Error: In margin_strut.cc, is_quirky_container_start triggers: 24px margin is dropped to 0px! Modeled in BlinkMarginStrut.v.
