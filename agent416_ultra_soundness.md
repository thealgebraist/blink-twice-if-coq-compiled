### I. PREAMBLE & AXIOMATIC DEFINITIONS

This audit formalizes the unification of the four core Blink Engine modules: the **Lexical-Syntactic Ingestion Frontend ($\mathcal{F}$)**, the **Linear Resource Type & Effect Checker ($\mathcal{T}$)**, the **Polyhedral Optimising Mid-End ($\mathcal{O}$)**, and the **Concurrent Lock-Free Execution Runtime ($\mathcal{R}$)**. 

Let a Blink configuration be a 5-tuple $\Sigma = \langle C, E, H, \Theta, \Omega \rangle$, where:
*   $C$: Control term (Abstract Syntax Tree / Continuation).
*   $E$: Lexical Environment mapping variables to Capabilities.
*   $H$: Linear Partitioned Heap, modeled as a partial commutative monoid $(H, \uplus, \emptyset)$.
*   $\Theta$: Thread Pool, a multiset of concurrent execution fibers $\theta_i = \langle C_i, E_i \rangle$.
*   $\Omega$: Ghost state tracking causal specification history and linear permissions.

We define the **Global Well-Formedness Predicate** $\vdash \Sigma : \text{OK}_\Delta$ relative to a global capability context $\Delta$, which holds iff the heap partitions cleanly across all active threads:
$$\Delta = \Delta_1 \circledast \Delta_2 \circledast \dots \circledast \Delta_n \quad \text{and} \quad H = H_1 \uplus H_2 \uplus \dots \uplus H_n$$
such that each fiber $\theta_i \in \Theta$ satisfies $\Delta_i; H_i \vdash \theta_i : \tau_i \ ! \ \mathcal{E}_i$ (type $\tau_i$ with bounded algebraic effect $\mathcal{E}_i$).

### II. THE ULTRA-SOUNDNESS METATHEOREM

**Theorem 1 (Blink Ultra-Soundness).**

$$\Sigma_0' \xrightarrow{\mathcal{R}}^k \Sigma_k' \implies \big(\text{Terminal}(\Sigma_k') \lor \exists \Sigma_{k+1}'. \ \Sigma_k' \xrightarrow{\mathcal{R}} \Sigma_{k+1}'\big) \land \vdash_{\mathcal{T}} \Sigma_k' : \text{OK}_{\Delta_k} \land (\Sigma_k' \approx_{\text{obs}} \Sigma_k)$$

### III. THE GRAND INDUCTIVE PROOF

We proceed by **Lexicographic Transfinite Induction** on the execution step index $k$ and the structural complexity metric $\mu(C)$ of the active control term, bridged by a **Stuttered Weak Bisimulation ($\mathcal{R}_{\sim}$)** between the unoptimized semantics and the $\mathcal{O}$-transformed runtime semantics.

#### 1. Base Case ($k = 0$): Ingestion and Static Validation
1.  **Frontend Totality ($\mathcal{F}$):** By the verified parser-combinator isomorphism, $\mathcal{F}(P)$ either rejects $P$ with a syntax error or emits a well-scoped AST $C_0$.
2.  **Initial State Synthesis:** $\Sigma_0 = \langle C_0, \emptyset, \emptyset, \{\theta_0\}, \Omega_0 \rangle$. Since $H_0 = \emptyset$ and $|\Theta| = 1$, the separation conjunction $\Delta_0$ is trivially satisfied.
3.  **Optimiser Simulation ($\mathcal{O}$):** Before execution, $\mathcal{O}$ applies polyhedral loop transformations and capability-aware inlining: $C_0 \leadsto_{\mathcal{O}} C_0'$. By the *Translation Validation Lemma* of $\mathcal{O}$, $\Delta_0 \vdash C_0 : \tau \implies \Delta_0 \vdash C_0' : \tau$ and $\langle C_0, \dots \rangle \mathcal{R}_{\sim} \langle C_0', \dots \rangle$.
4.  Thus, $\vdash \Sigma_0' : \text{OK}_{\Delta_0}$ holds at $k=0$. $\blacksquare_{\text{Base}}$

#### 2. Inductive Hypothesis (IH)
Assume that for an arbitrary step $k$, the configuration $\Sigma_k' = \langle C_k', E_k, H_k, \Theta_k, \Omega_k \rangle$ satisfies:
1.  **Invariant Preservation:** $\vdash_{\mathcal{T}} \Sigma_k' : \text{OK}_{\Delta_k}$.
2.  **Bisimulation:** There exists a specification state $\Sigma_k$ such that $\Sigma_0 \xrightarrow{\text{Spec}}^* \Sigma_k$ and $\Sigma_k \mathcal{R}_{\sim} \Sigma_k'$.
3.  **Heap Disjointness:** $\forall i \neq j, \ \text{dom}(H_{k,i}) \cap \text{dom}(H_{k,j}) = \emptyset$ for mutable capabilities.

#### 3. Inductive Step ($k \implies k+1$): Module Unification
We analyze the transition $\Sigma_k' \xrightarrow{\mathcal{R}} \Sigma_{k+1}'$ by case analysis on the operational semantics of the Runtime $\mathcal{R}$ and its interaction with $\mathcal{T}$ and $\mathcal{O}$.

##### Case A: Intra-Thread Pure & Effectful Reduction (Unifying $\mathcal{T}$ and $\mathcal{R}$)
Suppose thread $\theta_i$ reduces an expression $e \to e'$ with effect $\mathcal{E}$.
*   **Progress:** Since $\Delta_{k,i} \vdash e : \tau \ ! \ \mathcal{E}$, by the Canonical Forms Lemma, $e$ is either a value or a redex. If it is an algebraic effect operation $\text{op}(v)$, the static effect system $\mathcal{T}$ guarantees an enclosing handler $H_{\mathcal{E}}$ exists in the continuation stack of $\theta_i$. Thus, $\theta_i$ cannot get stuck.
*   **Preservation:** By the Substitution Lemma for Linear Capabilities, replacing $x$ with $v$ consumes the linear binding in $\Delta_{k,i}$ exactly once. The frame rule of Separation Logic ensures:
    $$\frac{\{H_{k,i}\} \ e \ \{H_{k+1,i}\} \quad H_{k,i} \perp H_{\text{rest}}}{\{H_{k,i} \uplus H_{\text{rest}}\} \ e \ \{H_{k+1,i} \uplus H_{\text{rest}}\}}$$
    Thus, $\vdash_{\mathcal{T}} \Sigma_{k+1}' : \text{OK}_{\Delta_{k+1}}$ is preserved.

##### Case B: Linear Memory Allocation & Deallocation (Unifying $\mathcal{T}$ and $H$)
Suppose $\theta_i$ executes `free(r)` where $r$ is a region capability.
*   The Type Checker $\mathcal{T}$ enforces affine/linear usage: $\Delta_{k,i} = \Delta'_{k,i}, r : \text{Cap}^{\text{lin}}(\rho)$.
*   Upon transition to $k+1$, the capability $r$ is annihilated in $\Delta_{k+1,i}$ (preventing Use-After-Free), and the physical memory partition $H_{\rho}$ is reclaimed: $H_{k+1} = H_k \setminus H_{\rho}$.
*   Because $\Delta_k$ is a separating conjunction ($\circledast$), no other thread $\theta_j$ ($j \neq i$) can possess an alias to $\rho$ in $\Delta_{k,j}$. Dangling pointers are structurally impossible.

##### Case C: Concurrent Lock-Free Synchronization (Unifying $\mathcal{R}$, $\Theta$, and $\Omega$)
Suppose $\theta_i$ executes an atomic Compare-And-Swap $\text{CAS}(\ell, v_{\text{old}}, v_{\text{new}})$ on a shared channel $\ell$.
*   By $\mathcal{T}$, shared locations must be wrapped in an invariant protocol $\mathcal{I}(\ell)$ governed by Ghost State $\Omega_k$.
*   The Runtime $\mathcal{R}$ executes a hardware-level atomic transition. We open the invariant $\mathcal{I}(\ell)$ for the duration of this single atomic step.
*   Ownership of the linear resource encapsulated by $v_{\text{new}}$ is transferred from $\Delta_{k,i}$ to the shared protocol $\mathcal{I}(\ell)$, while ownership of $v_{\text{old}}$ is transferred from $\mathcal{I}(\ell)$ to $\Delta_{k+1,i}$:
    $$\Delta_{k,i} \circledast \mathcal{I}(\ell) \Rrightarrow \Delta_{k+1,i} \circledast \mathcal{I}(\ell)$$
*   The Ghost State $\Omega_k \to \Omega_{k+1}$ logs the linearization point. Because the step is atomic, the invariant $\mathcal{I}(\ell)$ is immediately re-established. Data-race freedom holds trivially as concurrent accesses to $\ell$ are serialized by $\mathcal{R}$ and disjoint accesses are separated by $\uplus$.

##### Case D: Polyhedral & Mid-End Optimisations (Unifying $\mathcal{O}$ with $\mathcal{R}_{\sim}$)
Suppose the step $k \to k+1$ in $\Sigma'$ corresponds to a fused, vectorized, or reordered instruction block generated by $\mathcal{O}$.
*   $\mathcal{O}$ only permutes operations $(o_1, o_2) \to (o_2, o_1)$ if their dependency polyhedra are disjoint.
*   By the **Commutativity of Disjoint Heaps** (inherited from $\mathcal{T}$), operations on $H_a$ and $H_b$ (where $H_a \perp H_b$) commute observationally.
*   Therefore, if $\Sigma_k' \xrightarrow{\mathcal{R}} \Sigma_{k+1}'$ via an optimized instruction, either:
    1.  $\Sigma_k \xrightarrow{\text{Spec}}^m \Sigma_{k+1}$ ($m \ge 1$) such that $\Sigma_{k+1} \mathcal{R}_{\sim} \Sigma_{k+1}'$ (lock-step or macro-step simulation), or
    2.  $\Sigma_k = \Sigma_{k+1}$ and $\Sigma_k \mathcal{R}_{\sim} \Sigma_{k+1}'$ with a strictly decreasing stuttering measure $\mu(C_{k+1}') < \mu(C_k')$ (preventing infinite silent loops introduced by $\mathcal{O}$).
*   In both sub-cases, observational equivalence $\Sigma_{k+1}' \approx_{\text{obs}} \Sigma_{k+1}$ is maintained. $\blacksquare_{\text{Step}}$
