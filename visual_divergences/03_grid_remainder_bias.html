Divergence 4.1: CSS Grid Free Space Distribution

W3C CSS Grid 1 §11.5 Symmetric Sharing vs. Blink Re-Division Bias

When distributing 5px of residual free space across 3 identical tracks, CSS Grid demands symmetric expansion. Blink's integer re-division loop allocates 1px to Track 0, and 2px to Tracks 1 and 2, inducing an iteration-order asymmetry.
