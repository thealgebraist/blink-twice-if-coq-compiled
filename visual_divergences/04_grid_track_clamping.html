Divergence 4.2: Grid Line Limits

W3C CSS Grid 1 §8.3 Infinite Lattice vs. Blink kGridMaxTracks (100,000)

The W3C specification permits unbounded grid placement. To avoid memory exhaustion, Blink clamps tracks to 100,000. Clamping grid-column: 150000 / span 5 requires specialized span recovery to prevent a zero-span collapse bug.
