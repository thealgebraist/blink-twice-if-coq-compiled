## 1. Normative W3C WebGPU Specification Requirements

In the W3C WebGPU Specification (§7.3 *Samplers*), a `GPUSampler` object encapsulates sampling and filtering state used by programmable shader stages to sample texture data. Texture coordinate wrapping behavior along the U, V, and W texture axes is governed by the `GPUAddressMode` enumeration and configured via `GPUSamplerDescriptor`.

### 1.1 WebIDL Enumeration and Descriptor Definition
According to WebGPU §7.3.1 and §7.3.2:

```webidl
enum GPUAddressMode {
    "clamp-to-edge",
    "repeat",
    "mirror-repeat"
};

dictionary GPUSamplerDescriptor : GPUObjectDescriptorBase {
    GPUAddressMode addressModeU = "clamp-to-edge";
    GPUAddressMode addressModeV = "clamp-to-edge";
    GPUAddressMode addressModeW = "clamp-to-edge";
    GPUFilterMode magFilter = "nearest";
    GPUFilterMode minFilter = "nearest";
    GPUMipmapFilterMode mipmapFilter = "nearest";
    float lodMinClamp = 0;
    float lodMaxClamp = 32;
    GPUCompareFunction compare;
    [Clamp] unsigned short maxAnisotropy = 1;
};
```

### 1.2 Normative Semantic Requirements
1. **Default Initialization:** If `addressModeU`, `addressModeV`, or `addressModeW` is omitted in the JavaScript dictionary passed to `GPUDevice.createSampler(descriptor)`, the user agent *must* default the respective coordinate axis address mode to `"clamp-to-edge"`.
2. **Coordinate Wrapping Mathematics:** Given a texture coordinate $x$ and a discrete texture axis dimension $N > 0$ (indexed $0, 1, \dots, N-1$):
   * **`"clamp-to-edge"` ($0$):** Coordinates outside the $[0, N-1]$ domain are clamped to the nearest boundary index: $\max(0, \min(x, N-1))$.
   * **`"repeat"` ($1$):** Coordinates wrap periodically across the domain boundaries via Euclidean modulo: $x \bmod N$.
   * **`"mirror-repeat"` ($2$):** Coordinates wrap periodically over a $2N$ period, reflecting across odd multiples of $N$: Given $r = x \bmod (2N)$, the resolved index is $r$ if $r < N$, and $2N - 1 - r$ if $N \le r < 2N$.
3. **Exhaustive Translation:** Because V8's WebIDL binding layer validates that any incoming string matches a valid `GPUAddressMode` enumerator before entering Blink C++ implementation code, the internal translation from Blink's `V8GPUAddressMode` to the underlying graphics API (Dawn `WGPUAddressMode`) must be total, injective, and free of undefined behavior.

## 2. Chromium Blink Implementation Analysis

In Chromium, the renderer process translates WebIDL types generated by the V8 bindings into Dawn Wire C structures (`WGPUSamplerDescriptor`) inside `third_party/blink/renderer/modules/webgpu/gpu_sampler.cc` and `dawn_enum_conversions.cc`.

### 2.1 C++ Implementation Structure
When `GPUDevice::createSampler` invokes `GPUSampler::Create`, Blink converts the `GPUSamplerDescriptor` into a Dawn `WGPUSamplerDescriptor`:

```cpp
// third_party/blink/renderer/modules/webgpu/gpu_sampler.cc

namespace blink {

namespace {

WGPUSamplerDescriptor AsDawnType(const GPUSamplerDescriptor* webgpu_desc,
                                 std::string* label) {
  DCHECK(webgpu_desc);

  WGPUSamplerDescriptor dawn_desc = {};
  dawn_desc.nextInChain = nullptr;
  dawn_desc.addressModeU = AsDawnEnum(webgpu_desc->addressModeU());
  dawn_desc.addressModeV = AsDawnEnum(webgpu_desc->addressModeV());
  dawn_desc.addressModeW = AsDawnEnum(webgpu_desc->addressModeW());
  dawn_desc.magFilter = AsDawnEnum(webgpu_desc->magFilter());
  dawn_desc.minFilter = AsDawnEnum(webgpu_desc->minFilter());
  dawn_desc.mipmapFilter = AsDawnEnum(webgpu_desc->mipmapFilter());
  dawn_desc.lodMinClamp = webgpu_desc->lodMinClamp();
  dawn_desc.lodMaxClamp = webgpu_desc->lodMaxClamp();
  if (webgpu_desc->hasCompare()) {
    dawn_desc.compare = AsDawnEnum(webgpu_desc->compare());
  } else {
    dawn_desc.compare = WGPUCompareFunction_Undefined;
  }
  dawn_desc.maxAnisotropy = webgpu_desc->maxAnisotropy();
  if (webgpu_desc->hasLabel()) {
    *label = webgpu_desc->label().Utf8();
    dawn_desc.label = label->c_str();
  }

  return dawn_desc;
}

}  // namespace
```

The enum conversion function `AsDawnEnum(const V8GPUAddressMode& webgpu_enum)` maps the generated Blink V8 enum values (`kClampToEdge = 0`, `kRepeat = 1`, `kMirrorRepeat = 2`) to Dawn's `WGPUAddressMode`:

```cpp
WGPUAddressMode AsDawnEnum(const V8GPUAddressMode& webgpu_enum) {
  switch (webgpu_enum.AsEnum()) {
    case V8GPUAddressMode::Enum::kClampToEdge:
      return WGPUAddressMode_ClampToEdge;
    case V8GPUAddressMode::Enum::kRepeat:
      return WGPUAddressMode_Repeat;
    case V8GPUAddressMode::Enum::kMirrorRepeat:
      return WGPUAddressMode_MirrorRepeat;
  }
  NOTREACHED();
}
```

### 2.2 Implementation Invariants
1. **Ordinal Isomorphism:** In Blink's generated V8 bindings (`v8_gpu_address_mode.h`), `V8GPUAddressMode::Enum` assigns `kClampToEdge = 0`, `kRepeat = 1`, `kMirrorRepeat = 2`. In Dawn's `webgpu.h`, `WGPUAddressMode` assigns `WGPUAddressMode_Undefined = 0`, `WGPUAddressMode_ClampToEdge = 1`, `WGPUAddressMode_Repeat = 2`, `WGPUAddressMode_MirrorRepeat = 3` (or direct 0-based indexing in abstract specification models). In our formalization, we model the abstract specification ordinals $\{0, 1, 2\}$ and their exact structural preservation across the WebIDL-to-Dawn boundary.
2. **Absence of Uninitialized State (`Undefined`):** Because Blink's `.idl` file specifies default values (`= "clamp-to-edge"`) for `addressModeU`, `addressModeV`, and `addressModeW`, `webgpu_desc->addressModeU()` is guaranteed to hold one of the three valid variants. Thus, `WGPUAddressMode_Undefined` is unreachable at the `AsDawnEnum` boundary, and `NOTREACHED()` is dead code under well-typed V8 execution.
3. **Axis Orthogonality:** The translation of `addressModeU`, `addressModeV`, and `addressModeW` is pure and independent; mutating or configuring one axis cannot alias or corrupt another axis in `WGPUSamplerDescriptor`.

(** ** 1. WebGPU §7.3 Address Mode Types and Ordinal Encodings *)

(** WebIDL [GPUAddressMode] enumeration as represented in Blink V8 bindings
    ([V8GPUAddressMode::Enum]). *)
Inductive GPUAddressMode : Type :=
  | ClampToEdge  (* "clamp-to-edge" -> 0 *)
  | Repeat       (* "repeat"        -> 1 *)
  | MirrorRepeat (* "mirror-repeat" -> 2 *).

(** Scheme for decidable equality on [GPUAddressMode]. *)
Definition GPUAddressMode_eqb (m1 m2 : GPUAddressMode) : bool :=
  match m1, m2 with
  | ClampToEdge, ClampToEdge => true
  | Repeat, Repeat => true
  | MirrorRepeat, MirrorRepeat => true
  | _, _ => false
  end.

(** Mathematical ordinal mapping:
    clamp-to-edge(0), repeat(1), mirror-repeat(2). *)
Definition address_mode_to_Z (m : GPUAddressMode) : Z :=
  match m with
  | ClampToEdge  => 0
  | Repeat       => 1
  | MirrorRepeat => 2
  end.

(** Partial inverse from raw integer code to [GPUAddressMode]. *)
Definition Z_to_address_mode (z : Z) : option GPUAddressMode :=
  if Z.eqb z 0 then Some ClampToEdge
  else if Z.eqb z 1 then Some Repeat
  else if Z.eqb z 2 then Some MirrorRepeat
  else None.

(** Predicate characterizing valid mathematical address mode codes {0, 1, 2}. *)
Definition is_valid_address_mode_code (z : Z) : Prop :=
  0 <= z <= 2.

(** ** 2. Dawn Native Representation and Blink Conversion ([AsDawnEnum]) *)

(** Dawn native C ABI enum [WGPUAddressMode].
    Includes [WGPUAddressMode_Undefined] to model uninitialized C structs,
    allowing us to prove that Blink never produces the undefined state. *)
Inductive WGPUAddressMode : Type :=
  | WGPUAddressMode_ClampToEdge
  | WGPUAddressMode_Repeat
  | WGPUAddressMode_MirrorRepeat
  | WGPUAddressMode_Undefined.

  match d1, d2 with
  | WGPUAddressMode_ClampToEdge, WGPUAddressMode_ClampToEdge => true
  | WGPUAddressMode_Repeat, WGPUAddressMode_Repeat => true
  | WGPUAddressMode_MirrorRepeat, WGPUAddressMode_MirrorRepeat => true
  | WGPUAddressMode_Undefined, WGPUAddressMode_Undefined => true
  | _, _ => false
  end.

(** Models [AsDawnEnum(const V8GPUAddressMode&)] in Blink's
    [dawn_enum_conversions.cc], called by [gpu_sampler.cc]. *)
Definition AsDawnEnum (m : GPUAddressMode) : WGPUAddressMode :=
  match m with
  | ClampToEdge  => WGPUAddressMode_ClampToEdge
