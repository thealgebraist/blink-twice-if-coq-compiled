Divergence 8.2: Writing Modes

W3C CSS Writing Modes 3 vs. Blink Box Geometry Isomorphism

W3C defines vertical-rl and sideways-rl as distinct semantic modes. At the 2D layout geometry level, Blink's WritingModeConverter treats them as mathematically identical affine transformations; their differences are deferred entirely to glyph rotation.

writing-mode: vertical-rl (Upright CJK / Baseline)

Blink 垂直
Dimensions: 60px × 140px
Origin: Top-Right
Baselines: Central for CJK
✓ Box Geometry: Identical bounding box (60×140). Proven isomorphic in BlinkWritingModeConverter.v.

writing-mode: sideways-rl (Rotated 90° Clockwise)

Blink 垂直
Dimensions: 60px × 140px
Origin: Top-Right
Baselines: Rotated 90° Alphabetic
✗ Visual Divergence: Latin and CJK text rotated 90° clockwise, while physical box dimensions remain 100% invariant.
